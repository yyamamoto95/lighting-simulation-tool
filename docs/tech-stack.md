# 技術スタック

## 採用スタック

### フロントエンド

| 技術 | 用途 | 採用理由 |
|------|------|---------|
| **Vite** | バンドラー・開発サーバー | 高速 HMR・シンプルな設定 |
| **TypeScript** | 言語 | 型安全・チーム開発対応 |
| **Three.js** | 3D レンダリング | WebGL の実績・豊富な3D API |

### バックエンド

| 技術 | 用途 | 採用理由 |
|------|------|---------|
| **Node.js** | ランタイム | フロントエンドと言語統一 |
| **Hono** | Web フレームワーク | TypeScript-first・軽量・型安全なルーティング |
| **TypeScript** | 言語 | フロントと統一 |

### データ永続化

| 技術 | 用途 | 採用理由 |
|------|------|---------|
| **SQLite** | データベース | サーバーレス・ファイル1本・運用コストゼロ |
| **Prisma** | ORM | 型安全なクエリ・マイグレーション管理 |

### 開発ツール

| 技術 | 用途 | 採用理由 |
|------|------|---------|
| **Biome** | Linter / Formatter | ESLint + Prettier の代替・高速・設定が少ない |
| **Vitest** | テスト | Vite と統合・TypeScript ネイティブ |
| **pnpm** | パッケージ管理 | 高速・ディスク効率・厳格な依存解決 |
| `.nvmrc` | Node.js バージョン固定 | チーム間での環境統一 |

## バージョン方針

各パッケージは **実装開始時点の最新安定版（LTS）** を採用する。

## 将来拡張に備えた設計方針

### URLリアルタイム共有（将来）
- **Socket.io** をバックエンドに組み込む想定
- MVP 時点では実装しないが、プロジェクト（セッション）単位でデータを管理する DB 設計にしておく

### 会場モデル追加（将来）
- 会場モデルを差し替え可能な構造にする（ハードコードしない）
- 会場定義を設定ファイル（JSON 等）で管理する

## ディレクトリ構成（案）

```
lighting-simulation-tool/
├── client/                  - フロントエンド（Vite + TS + Three.js）
│   ├── src/
│   │   ├── scene/           - Three.js シーン・カメラ・レンダラー
│   │   ├── lights/          - 照明オブジェクトの生成・管理
│   │   ├── venues/          - 会場モデルの定義
│   │   ├── ui/              - GUIコンポーネント
│   │   ├── animation/       - モーション・アニメーション
│   │   └── main.ts          - エントリポイント
│   └── vite.config.ts
├── server/                  - バックエンド（Hono + TS）
│   ├── src/
│   │   ├── routes/          - API ルーティング
│   │   ├── db/              - Prisma クライアント・スキーマ
│   │   └── index.ts         - エントリポイント
│   └── prisma/
│       └── schema.prisma
├── docs/                    - ドキュメント
├── biome.json
├── pnpm-workspace.yaml      - モノレポ構成（client / server）
└── .nvmrc
```

## 現行からの主な変更点

| 変更前 | 変更後 |
|--------|--------|
| Plain JavaScript | TypeScript |
| インライン `<script>` | モジュール分割 |
| グローバル変数 | モジュールスコープ |
| dat.GUI | カスタム UI |
| jQuery | 廃止 |
| CSV ファイル | SQLite + Prisma |
| なし | Biome / Vitest |
| npm | pnpm |
